Document Purpose & Scope
This Software Requirements Specification (SRS) defines the complete functional scope of the Amora mobile application.
It documents every module, screen, field, and interactive element exactly as approved in the master feature list — with
no items added or removed — so that design, engineering, QA, and stakeholder teams operate from a single,
unambiguous reference.
Amora is a dating and matchmaking application built around swipe-based discovery, AI-driven compatibility matching,
real-time chat, in-person and community events, identity verification, and a tiered membership model.
Each numbered module below corresponds one-to-one with the source documentation. Every table lists the feature or
field on the left and its functional explanation on the right.
