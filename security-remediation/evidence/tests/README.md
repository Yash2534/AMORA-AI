# Test evidence

Place redacted test logs, JUnit/Flutter reports, isolated test-database metadata, command manifests, and CI run references here. Record exit codes and failures; never relabel an unexecuted command as passing.

Runtime evidence from the 2026-10-09 local validation is stored in the `backend/`, `flutter/`, `secrets/`, `dependencies/`, and `static/` subdirectories. These summaries disclose failed and blocked commands; they do not substitute for missing external proof.
