# Monitoring Evidence

- Acceptable: dashboard/rule exports, approved thresholds/severity, real destinations, named owner references, staging alert delivery/escalation and linked runbooks.
- Unacceptable: invented on-call names, templates, screenshots without rule IDs/times, or production-impacting tests.
- Redact: private contacts, tokens, customer data and unrelated alerts; retain rule ID, signal, severity, timestamps and delivery/escalation outcome.
- Provider: SRE/Security/Management-designated owners.
- Pass: every mandatory signal is configured, owned, documented and successfully tested in approved staging.
