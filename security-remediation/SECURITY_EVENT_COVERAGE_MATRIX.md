# Security Event Coverage Matrix

Scope: repository event coverage for P-13. `AdminAuditLogs` is the shared, sanitized, hash-chained repository sink; `UserLoginEvents`, `UserTimelineEvents`, `ConsentEvents`, and identity decision events remain domain-specific supporting sinks. Production append-only roles, centralized ingestion, retention, alerts, and time synchronization remain P-39 infrastructure evidence and are not claimed here.

All shared security events include a server-generated or validated correlation ID, request IP, bounded user agent, actor type/ID when authenticated, target type/ID where available, outcome, HTTP status, and a one-way device reference when `x-device-id` is supplied. Request bodies are never copied into security-event metadata. The existing recursive sanitizer redacts credentials, OTP/token/cookie/MFA/API-key/private-key/identity-number fields and nested values.
