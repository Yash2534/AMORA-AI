# Security Policy

Report suspected vulnerabilities privately to the company-designated security contact. The real address and backup channel must be assigned by Management before publication; do not place credentials, identity documents, customer data or exploit payloads in a public issue.

Include affected commit/build, component, preconditions, minimum harmless reproduction using dummy data, observed result and suggested remediation. Do not access production data, disrupt availability, evade monitoring, persist access or publish before coordinated review.

Repository maintainers should acknowledge, triage, contain, remediate, test and disclose through the approved incident and vulnerability-management processes.
