# Development-only synthetic portrait sources

This directory is populated by `npm run setup:demo-portrait-assets`. It holds
200 AI-generated portrait files from the Faker `assets-person-portrait`
collection, licensed under CC0-1.0:

<https://github.com/faker-js/assets-person-portrait>

These are development/demo source assets only. They are copied into the local
ignored upload directory only when the guarded dummy seed command runs. They
must not be used to represent real customers or production users.
