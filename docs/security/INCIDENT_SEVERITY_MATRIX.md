# Incident severity matrix

| Level | Repository-neutral trigger | Response posture |
|---|---|---|
| SEV-1 | Confirmed broad credential compromise, active server compromise, material personal-data exfiltration, or widespread public protected-media exposure | Immediate incident command, containment, executive/legal engagement, continuous handoff |
| SEV-2 | Confirmed limited compromise, high-confidence admin takeover, sustained OTP abuse, or third-party breach plausibly affecting AMORAA data | Urgent containment, scoped investigation, frequent updates |
| SEV-3 | Contained suspicious activity, low-volume abuse, or a security control failure without confirmed data access | Same-business-cycle triage and corrective action |
| SEV-4 | Security observation, unsuccessful probing, or policy/process gap with no immediate exposure | Track through normal vulnerability management |

Severity can increase as evidence changes. Notification obligations and deadlines are intentionally omitted pending legal verification.
