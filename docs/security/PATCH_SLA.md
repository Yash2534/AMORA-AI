# Patch SLA (Approval Required)

Proposed targets, pending Management/Security approval:

- Critical: immediate containment and highest-priority remediation; production release blocked until independently closed.
- High: prompt remediation in the next controlled release or time-bounded written risk acceptance with compensating controls and independent retest.
- Medium/Low: prioritized by demonstrated impact, exposure and dependency lifecycle.

No numerical deadline is asserted until owners approve it. Each exception records severity evidence, affected versions, owner, due date, compensating control, expiry and approver. Internet-exposed/authentication/payment/KYC/media/chat/database/cloud changes require security review.
