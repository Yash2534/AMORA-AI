# Design System Report

The frontend uses centralized color, typography, spacing, radius, shadow, gradient, icon, and motion modules under `lib/core/theme`.

- Spacing scale: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64
- Core radii: 16, 18, 20, 24, 28, 32, pill
- Button/input minimum height: 56 px
- Icon-button touch target: 44 px
- Motion: 160/200/240 ms with a shared cubic curve
